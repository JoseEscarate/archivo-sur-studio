# Archivo Sur Studio

Sitio web estático de Archivo Sur Studio, dedicado a comunicación y narrativa digital.

## Desarrollo local

Abre `index.html` en un navegador o inicia un servidor estático desde esta carpeta:

```powershell
py -m http.server 8000
```

Luego visita <http://localhost:8000>.
